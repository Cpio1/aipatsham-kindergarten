# «Ай Патшам» балабақшасы — лендинг

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Motion · Lucide.
Сайт по умолчанию на казахском, переключатель ҚАЗ / РУС сохраняет выбор в браузере.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production-сборка (готово к Vercel)
```

## Фотографии (папка `public`)

Сайт сам находит файлы при сборке. Если файла нет, показывается иллюстрация, а не битая картинка.
Форматы: PNG, JPG, JPEG, WebP, AVIF.

| Файл                    | Где используется              |
| ----------------------- | ----------------------------- |
| `public/logo.*`         | Header, футер, контакты       |
| `public/main-page.*`    | Главный экран (Hero)          |
| `public/main-page2.*`   | Раздел «Біз туралы»           |
| `public/gallery/*`      | Галерея (сортировка по имени) |
| прочие картинки в `public/` | тоже попадают в галерею  |

После добавления фото нужен новый деплой (или `npm run build`).
Фавикон лежит в `src/app/icon.svg`. Если появится настоящий логотип, замените его на `src/app/icon.png`.

## Данные

- `src/data/site.ts`: телефон, WhatsApp, Instagram, режим работы, ссылка 2GIS, документы.
- `src/data/content.ts`: все тексты на казахском и русском.

**2GIS:** точное местоположение не подтверждено, поэтому кнопка открывает поиск 2GIS по адресу «Көктем-1, 11».
Если у вас есть ссылка на карточку организации, вставьте её в `mapUrl`.

**Документы:** добавьте записи в `documents` и/или `documentsDriveUrl` в `site.ts`. Пока список пуст, показывается сообщение «Құжаттар жақында қосылады».

## Структура

```
src/
  app/            layout, page, icon, OG-картинки
  components/
    desktop/      Desktop* — композиции для экранов ≥1024px
    mobile/       Mobile*  — отдельные композиции для экранов <1024px
    shared/       общие блоки (лайтбокс, логотип, декор, документы, футер…)
    ui/           кнопки
  data/           данные и переводы
  lib/            i18n, хуки, чтение изображений
  styles/         globals.css (палитра, только светлая тема)
```

Деплой на Vercel: импортируйте репозиторий, настройки по умолчанию. При желании задайте `NEXT_PUBLIC_SITE_URL` (домен для Open Graph).
